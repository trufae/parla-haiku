Fixes **“package parla-0.1.0-1 is not installable”** on standard 32-bit Haiku (x86_gcc2).

Download `parla_x86-0.1.0-2-x86_gcc2.hpkg` and install with:

```sh
pkgman install ./parla_x86-0.1.0-2-x86_gcc2.hpkg
```

The original package incorrectly declared the OS architecture as `x86`.
Haiku's hybrid system requires `architecture x86_gcc2`, even for binaries built
with modern GCC. This revision uses the conventional `parla_x86` package name
and retains the `haiku_x86` secondary-runtime dependency.

Both executables are byte-for-byte identical to the original build; only the
package metadata changed. CI verifies the original download checksum, the new
metadata and both executable checksums after extracting the repaired package.
Installation and execution on 32-bit Haiku still need real-system validation.

The [64-bit package from v0.1.0](https://github.com/trufae/parla-haiku/releases/download/v0.1.0/parla-0.1.0-1-x86_64.hpkg) is unchanged.
