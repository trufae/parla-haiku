First native Haiku preview of Parla, using C++ Interface Kit widgets and Chatmail core 2.63.0.

## Downloads

- **64-bit Haiku:** `parla-0.1.0-1-x86_64.hpkg`
- **32-bit Haiku:** `parla-0.1.0-1-x86.hpkg` (modern GCC secondary ABI on Haiku's hybrid x86 system; not a GCC 2 / BeOS binary)
- `SHA256SUMS` contains checksums for both packages.
- `parla-native.png` shows the application running in the Haiku CI VM.

Open the matching `.hpkg` in Haiku to install it, then launch Parla from Deskbar.
Use **Profile → New profile**, then exchange invitation links with another Delta Chat user.
Enter sends a message; Shift+Enter inserts a newline.

## Included

Native menus, split views, system fonts/colors, profile setup, multiple profiles,
chat lists, groups and invitations, text and file messages, replies, edits,
reactions, delivery states, read receipts, message history, local drafts,
notifications and backup import/export. The app starts its own bundled core
over private stdio JSON-RPC; no separate server installation is required.

The core port uses OpenSSL 3.5.9 and narrowly scoped Haiku networking patches.
TLS and OpenPGP checks remain enabled. Both architectures use cross-built Rust
cores to avoid invalid objects produced by the current native Rust toolchain.
The 64-bit GUI is built natively in Haiku.

## Validation and remaining work

Both packages come from successful CI builds with identical application and
core build inputs; the release verifies these against the tagged source.
The 64-bit job runs in Haiku R1/beta6 and checks transport behavior, the real
core with offline profiles and attachments, and the native GUI/core handshake.
The 32-bit job verifies both executables are ELF32 and builds the real package;
**execution on a 32-bit Haiku installation remains untested**.

This is a development preview for real-OS testing. Live account provisioning,
mail delivery and interoperability with another Delta Chat device still need
end-to-end validation on Haiku. Webxdc, voice/video and inline media are not
implemented. Name and artwork are provisional.

Profiles and keys are stored in `~/config/settings/Parla`. Export a backup
before deleting that directory or replacing an existing profile.
